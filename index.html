🚀 How to Host on Your Personal `github.io`

Step 1: Save This Game as `index.html`

Click the button to download this complete single-file web app.

Step 2: Upload to GitHub Pages (2 Minutes, 100% Free)

  1. Log in to github.com and click the + (New repository) icon in the top-right corner.
  2. Name the repository baby-shower (or yourusername.github.io), set it to Public, and click Create repository.
  3. On the next screen, click the link that says "uploading an existing file".
  4. Drag and drop your downloaded index.html file into the box and click the green Commit changes button.
  5. Click Settings (top tab) ➔ Pages (left sidebar). Under Branch, change None to main and click Save.
  6. Wait ~60 seconds, then open https://yourusername.github.io/baby-shower/ on your TV/laptop!
